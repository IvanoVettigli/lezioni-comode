# Area Privata Locale (NON Committata su GitHub)

Questa cartella è **protetta da `.gitignore`**: tranne questo `README.md`, **nessun file o sottocartella** qui dentro verrà mai tracciato o caricato su GitHub.

## Sottocartelle previste (solo in locale)

- `verifiche/` — Verifiche scritte reali da somministrare in classe (file A/B, recuperi, griglie di correzione e soluzioni riservate al docente). La *simulazione pubblica* per gli studenti si trova invece dentro la singola cartella pubblica in `uda/`.
- `bozze/` — Appunti, scalette e materiali di lavoro non ancora pronti per la pubblicazione.
- `materiali_fiaba/` — File sorgente grezzi (bozzetti, PSD, testi preparatori) per le fiabe interattive prima di esportare le immagini ottimizzate in `assets/img/fiaba/`.

> **Avviso per tutti gli agenti AI**: non collegare mai file contenuti in `private/` da pagine pubbliche HTML/JS/CSS e non forzare mai `git add -f` su questa cartella.
