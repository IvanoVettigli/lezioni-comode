## Promemoria rapido per Claude

Prima di qualsiasi azione su questo repository, leggi integralmente [AGENTS.md](AGENTS.md) e, quando lavori su contenuti didattici, gamification, architettura o stampa PDF, consulta i relativi file in `docs/`.

Regole inderogabili:
1. **Mai cancellare file o cartelle** senza esplicita approvazione dell'utente.
2. **Mai eseguire `git commit` o `git push`** senza espressa richiesta o autorizzazione dell'utente.
3. **Mai committare o linkare pubblicamente** i contenuti della cartella `private/`.
4. **Usa sempre le librerie, il CSS (`assets/css/`) e il JS (`assets/js/`) condivisi** e i template in `templates/` per mantenere tutte le UDA perfettamente uniformi.
5. Dopo modifiche strutturali o aggiunta di UDA, esegui `python tools/validate_project.py`.
